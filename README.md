# MRT TOOLS Digital Products

Private repository for the MRT TOOLS digital product access platform.

## Current stage

- Public product catalogue UI
- Product access entry point
- Dark/light theme foundation
- Responsive marketplace-style layout
- Support section
- Authentication and order verification are planned for the backend stage
- Vercel deployment is intentionally deferred

## Planned architecture

Next.js App Router + JavaScript, with server-side authentication and order-to-product entitlement checks before protected product content is exposed.
